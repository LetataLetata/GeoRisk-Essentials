GEORISK Observatory · how the app is built

From open data to a decision, in six steps

GEORISK Observatory is an R Shiny dashboard that applies spatial statistics to the INFORM Risk Index for 191 countries. It is built around one chain of questions: what is in the data, where risk is concentrated, whether the disaster events themselves cluster, what explains it, how sure we can be, and where action should come first.

1 · The idea

One question per step, each feeding the next

Every step page opens with a one-sentence answer computed from the data, shows one main figure, and ends with a button to the next step. Explore lets anyone click a single country.

Step 1 · DescribeWhat is in the data?Descriptive statistics, distributions, Spearman correlations by continent
Step 2 · LocateWhere is risk concentrated?Global and local Moran's I for any of 33 INFORM variables
Step 3 · DetectAre the events themselves clustered?Point pattern of 23,409 earthquakes: kernel density, quadrat test, nearest-neighbour index, G and L functions
Step 4 · ExplainWhat explains it?Regression on wealth, Lagrange multiplier tests, spatial error model
Step 5 · TestHow sure can we be?Monte Carlo uncertainty, reliability adjustment, robustness
Step 6 · DecideWhere should action come first?Danger meets vulnerability: bivariate classes and Lee's L
2 · System architecture

Five layers, each replaceable on its own

Raw data is prepared once into compact files. Plain R functions do the statistics, a cache keeps every result, and each page is an independent module, so a broken page never takes the others down.

3 · App logic

What happens when someone changes a setting

The same path runs for every analysis, so missing data, neighbours and caching are handled the same way everywhere.

  1. Missing data first. Each analysis lists the variables it needs; countries without all of them are left out, shown grey on the maps and named under the answer.
  2. Neighbours fit the countries analysed. The five nearest neighbours are rebuilt for exactly those countries, so a missing country is never anyone's neighbour.
  3. Computed once. Results are stored and shared; for the presentation every option is precomputed, so changing a setting only redraws.
  4. Maps are recoloured, not rebuilt. Country shapes are sent once; later only colours, labels and the legend change.
4 · Wireframes

Four screen layouts carry the whole app

Every step page uses the same template, so a reader learns the layout once. Panels fold, the top bar has Fold all, Unfold and Compact, and every map can be enlarged, resized by dragging its corner, or made full screen.
